プライバシーポリシー

最終更新日: 2026年9月6日

1. 運営者

高橋 秀臣（Web制作業。屋号はありません）。本ポリシーは、運営者が開発し利用する「TAMI Inc. Connector」（以下「本アプリ」）に適用されます。

2. 本アプリの性質

本アプリは、運営者自身の業務を自動化するための内部ツールです。利用者は運営者本人のみで、第三者への提供・配布は行いません。

3. 取得する情報

本アプリは、Google アカウントの認可（OAuth）を通じて、次の情報にアクセスします。

  • Gmail: メールの閲覧、整理（ラベル付けなど）、下書きの作成、送信（スコープ: gmail.modify）
  • Gmail の基本設定の閲覧（スコープ: gmail.settings.basic）

Google カレンダーや Google スプレッドシートなど、対象を追加する場合は本ポリシーを更新します。パスワードは取得・保持しません。

4. 利用目的

  • 顧客からのメールを整理し、案件管理の台帳に紐付けるため
  • 返信文の下書きを作成するため（送信は運営者が内容を確認し、承認したものだけを行います）
  • 見積・請求・進捗管理を補助するため

5. 保存と安全管理

認可トークンおよび取得した情報は、運営者のパソコン内にのみ保存します。外部サーバーへの複製・保管は行いません。保存するファイルはアクセス権限を制限し、運営者以外が読めない状態で管理します。

6. AI サービスの利用

メールの要約や返信案の作成のために、必要最小限の範囲で AI サービス（Anthropic の Claude など）の API に処理を依頼することがあります。送信する内容は処理に必要な範囲に限り、広告目的には利用しません。

7. 第三者への提供

法令に基づく場合を除き、取得した情報を第三者に提供・販売することはありません。

8. Google API サービスのユーザーデータに関するポリシーの遵守

本アプリが Google API から受け取った情報の使用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に準拠します。

9. アクセスの取り消し

Google アカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」から、本アプリのアクセスをいつでも削除できます。削除後、運営者はパソコン内の認可トークンを削除します。

10. ポリシーの改定

内容を変更する場合は、本ページで公開します。
